# カタログの公開手順

GitHub Pages版の公開カタログは、mainブランチの`config/menu_catalog.json`からビルドされます。

## メニューを変更する場合

1. 管理画面でメニュー、単品ベクトル、階層の有効状態を変更する。
2. 「JSONを書き出す」で`menu_catalog.json`を保存する。
3. リポジトリの`config/menu_catalog.json`を、書き出したファイルで置き換える。
4. 変更をcommitしてmainへpushする。
5. GitHub Actionsがfrontendをビルドし、GitHub Pagesへデプロイする。

管理画面の編集結果は、その端末のlocalStorageにだけ保存されます。静的なGitHub Pagesからリポジトリへ自動pushすることはありません。mainの内容を変更するには、JSONをcommitする運用にします。

## 既存端末へ公開版を反映する場合

localStorageのカタログが同梱カタログより優先されるため、mainを更新しても既存端末の編集内容は自動では上書きされません。公開後、管理画面で「公開版を読み込む」を押してください。端末内のカタログが置き換わるため、必要なら先にJSONを書き出します。

localStorageはブラウザ・サイトの組み合わせごとの保存領域です。別の端末や別のブラウザとは共有されず、プライベートブラウジング、サイトデータの削除、ブラウザのストレージ削除では失われる可能性があります。
